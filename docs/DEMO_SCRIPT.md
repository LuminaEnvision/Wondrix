# Wondrix — championship demo script (≈3 minutes)

**Event:** Dubai Create AI Agents Championship · Best Societal AI Agent  
**Proof story:** quiet gap found by radar → Extra grown (diagram + voice) → parent summary  
**Team:** Anastasia (product) · Jorge Cristo (AI agents / voice / visuals)

Record in **Chrome**, phone or tablet frame if you can. Use a fresh profile (or clear site data) so setup looks intentional.

---

## Prep (before record)

1. `npm run build && npm start` (smoother than `dev` on camera).
2. `.env.local` with `ZAI_API_KEY` set (live agents + diagrams).
3. Mic permission allowed; speakers on; voice answers **on**.
4. Parent once: nickname **Alex**, grade **Year 5**, subjects math + science, teacher note: `Teacher said fractions need practice`.
5. Do one dry run so Kokoro’s first download is done (or accept the loading bubble on camera).

**Camera path:** Home → Parent (quick) → School radar → School this week → Extra → Parent summary.

---

## Script

### 0:00–0:25 · Hook + home

**On screen:** Home, two doors, mascot.

**Say:**
> This is Wondrix, our friend on the learning path. Built for the Dubai Create AI Agents Championship, Best Societal AI Agent.
>
> Two doors. School finds quiet learning gaps. Extra grows curiosity. Parents get a daily summary. No scary scores.

**Do:** Pause on home. Tap **School** only after the line.

---

### 0:25–0:50 · Parent steers once

**On screen:** Parent (unlock if needed). Show grade + teacher recommendations.

**Say:**
> A parent sets grade and subjects once. After a teacher call, they can leave a short recommendation. Today: Year 5, and the teacher said fractions need practice.
>
> Calm mode is here for rough days. We save, and the School agent will use this.

**Do:** Scroll to teacher field (already filled). Tap Save if needed. Back → Home → **School**.

---

### 0:50–1:25 · Gap radar (silent delay)

**On screen:** School → Gap radar. Answer 2–3 items. On one item choose **I don’t know yet**.

**Say:**
> Many delays stay invisible because a child never raises a hand. Gap radar is a short check. I don’t know is always okay.
>
> Watch: when Alex is unsure, Wondrix marks that skill as shaky. No percent score. No confession required.

**Do:** Finish enough of radar to return to This week, or Back to This week after 2–3 answers.

---

### 1:25–1:55 · School agent this week

**On screen:** This week. Point at focus skills and the short reason under each.

**Say:**
> The School agent reads grade, mastery, and the teacher note. It picks one or two focus skills and tells us why.
>
> Practice is soft: try an answer, or say I don’t know. The agent explains. Mistakes grow the skill quietly.

**Do:** Tap **Start** on fractions / comparing fractions if shown. Answer one question (right or wrong). Show the short tip. Back to School or Home.

---

### 1:55–2:35 · Extra agent (answer → follow-up → diagram → voice)

**On screen:** Extra chat.

**Say:**
> Door two is Extra. Same agent family, different job: grow curiosity.
>
> Alex asks: how does rain happen?

**Do:** Type or mic: `How does rain happen?` Send. Wait for answer + one follow-up. When the diagram draws, pause on it.

**Say:**
> Wondrix answers clearly, then asks one gentle follow-up. The diagram is built on the spot from the agent’s plan. Not stock art.
>
> And the child can listen.

**Do:** Tap **Listen**. Let 1–2 sentences play. Stop if needed.

---

### 2:35–2:55 · Parent summary

**On screen:** Parent → today’s phone summary.

**Say:**
> At the end of the day, the parent sees a phone-style summary: what School practiced, what Extra explored, and a calm tip if needed. Unsafe questions are redirected, and the summary only shows a count, never the text.

**Do:** Hold on the summary card 3–4 seconds.

---

### 2:55–3:10 · Close

**On screen:** Home again (or freeze on summary).

**Say:**
> Quiet gap found. Curiosity grown. Parent informed. That’s Wondrix: a societal AI agent for learning at home.
>
> Team: Anastasia and Jorge Cristo. Thank you.

---

## Short cut (90 seconds) if time is tight

1. Home (5s)  
2. Parent teacher note (10s)  
3. Radar + “I don’t know” (20s)  
4. This week focus + reason (15s)  
5. Extra: rain + diagram + Listen (30s)  
6. Parent summary + close (10s)  

---

## B-roll / cutaways (optional)

- Mascot on the path hero  
- Equalizer on Speaking  
- Diagram drawing in  
- Phone mock of the summary card  

## Avoid on camera

- Long waits with no VO (cover with the “agent is thinking” line)  
- Opening `.env` or API keys  
- Unsafe / redirect demos unless you want a 5-second safety beat  
- Emphasizing “demo fallback” if the live key is working  

## Backup line if AI is slow

> While the live agent thinks, the app never freezes. If the model is busy, Wondrix still has a local path so learning continues.
