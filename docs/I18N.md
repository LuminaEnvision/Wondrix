## How it works

- Language is saved in the profile (`profile.language`), so every API call already carries it.
- Text lives in `src/lib/i18n/en.ts` (source) and `src/lib/i18n/ar.ts`. TypeScript fails if a key is missing in Arabic.
- Screens use `const tr = useT(); tr("extra.send")`; placeholders look like `{name}`.
- The picker is in the first-run setup and in Parent. It applies at once, without Save.
- **Test guard:** `tests/unit/i18n.test.ts` fails if a screen has hard-coded English text, or if the Arabic draft is missing a key or a `{placeholder}`.

## For the native-speaker reviewer

- Edit only the text on the right side in `src/lib/i18n/ar.ts`. Keep keys and `{placeholders}`.
- Or send corrections as a list (`key → new text`) and we paste them in.
- Tone: friendly and simple for ages 7 to 13, Modern Standard Arabic. Use Western digits (0-9).
- Please also try Extra in Arabic: ask a few questions and check the answers sound natural for a child.

## RTL rules for the redesign (Anastasia)

1. Use **logical** spacing and position classes: `ms-/me-` (not `ml-/mr-`), `ps-/pe-`, `start-/end-` (not `left-/right-`), `text-start/text-end` (not `text-left/right`). Flex rows flip on their own.
2. Icons that mean direction (back arrow, "next") flip in RTL with `rtl:-scale-x-100`. Play, mic and check icons do not flip.
3. Text the user or the AI writes gets `dir="auto"`, so mixed Arabic/English shows the right way.
4. English-only content in an Arabic screen (grade names in selects) gets `dir="ltr"`.
5. Extra diagrams stay left to right for now (`dir="ltr"` on the SVG); the Arabic labels inside read correctly.
6. Fonts: Fraunces and Nunito have no Arabic letters, so the browser falls back to a system Arabic font. For the final design, pick a matching Arabic font (for example Tajawal or Noto Kufi Arabic).
